# EduCore Academy - Course and Assessment Platform

## Contexto de la Organización
EduCore Academy opera una plataforma web institucional que gestiona la inscripción de alumnos, la entrega de tareas interactivas y la consulta de calificaciones. Ante el inicio de un nuevo periodo escolar y la actualización de su plataforma, el comité técnico ha solicitado una auditoría preliminar de seguridad para revisar el repositorio y detectar malas prácticas o configuraciones de riesgo antes del lanzamiento.

## Objetivo de la Fase 1
Los alumnos deben realizar un análisis preliminar y un plan de auditoría **sin ejecutar herramientas de escaneo en esta etapa**, inspeccionando la estructura del proyecto y los archivos clave para identificar los riesgos esperados.
